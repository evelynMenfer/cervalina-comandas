# Cervalina Comandas

Punto de venta para tablet: comandas por mesa, cocina y barra, cobro con ticket impreso por Bluetooth, caja e inventario de insumos.

- `public/`: la app que se publica (Netlify: directorio de publicación `public`, sin comando de compilación).
- `public/config.js`: configuración del proyecto de Firebase.
- `public/seed.json`: carta e insumos iniciales.
- `firestore.rules`: reglas de seguridad de la base de datos.
- `GUIA.md`: instalación paso a paso.
